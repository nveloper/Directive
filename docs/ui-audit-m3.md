# Material 3 기준 재평가

앱이 Material You 색 체계를 쓰므로, 기준도 Google Material 3(m3.material.io)의 토큰을 그대로 가져온다.
측정은 폰(412×915)과 11인치 태블릿 가로(1194×834)에서 목록·상세 화면의 실제 DOM 값으로 했다.

## 기준

| 항목 | M3 기준 |
|---|---|
| 글자 | 정해진 스케일만 사용: Title L 22/28, Title M 16/24·500, Title S 14/20·500, Body L 16/24, Body M 14/20, Body S 12/16, Label L 14/20·500, Label M 12/16·500, Headline S 24/32, Headline M 28/36 |
| 줄 높이 | 4의 배수 고정값(16·20·24·28·32·36) |
| 간격 | 4dp 격자. 보통 4·8·12·16·24 |
| 화면 여백 | 폰 16, 태블릿 24 |
| 터치 영역 | 최소 48×48dp (보이는 크기가 작아도 누르는 영역은 48) |
| 목록 항목 | 1줄 56, 2줄 72. 좌우 안쪽 여백 16, 앞 아이콘 24 |
| 탭 | 높이 48 |
| 버튼 | 높이 40, 모서리 완전 둥글게 |
| 모서리 | 4·8·12·16·28·완전 둥글게 중 하나 |
| 정렬 | 한 화면에서 글자 시작선은 2~3개로 제한 |

## 측정 결과

| 항목 | 현재 | 판정 |
|---|---|---|
| 글자 조합 | 상세 화면에만 10가지. 13px·15px처럼 스케일에 없는 크기 사용 | 미달 |
| 줄 높이 | 1.45 비율이라 17.4·18.85·20.3·21.75·25.5px 같은 소수 값 | 미달 — 행마다 기준선이 어긋나 보이는 주원인 |
| 터치 확대 | `zoom` 1.08/1.15를 곱해서 모든 값이 격자를 벗어남(예: 13px→14.95px) | 미달 — 지난번 조치가 오히려 격자를 깨뜨림 |
| 간격 | 2·3·5·6·7·9·10px가 섞여 있음 | 미달 |
| 터치 영역 | 상세 화면에 19·24·35px짜리 버튼(체크리스트 이동·삭제, 선택 상자) | 미달 |
| 탭 높이 | 43px | 미달(48) |
| 목록 항목 | 74~79px | 근접(72) |
| 모서리 | 4·8·16·28·완전 둥글게 | 통과 |
| 정렬선 | 목록: 아이콘 시작선 2개(15·19). 상세: 본문 시작선 외에 45·49·53·54·55px 등 비슷하지만 다른 선 다수 | 미달 — "정갈하지 못하다"는 인상의 두 번째 원인 |

## 고칠 순서

1. `zoom`을 걷어내고, 글자를 M3 스케일 토큰(크기·줄 높이·굵기 묶음)으로 교체. 터치 화면에서는 토큰 단계를 올리는 방식으로 키운다.
2. 모든 간격을 4·8·12·16·24로 맞추고, 화면 여백을 폰 16 / 태블릿 24로 고정.
3. 정렬선 정리: 목록은 아이콘 열(16)과 글자 열(56) 두 개, 상세는 라벨 열과 값 열 두 개.
4. 누르는 요소는 모두 48 이상(보이는 아이콘은 24 유지, 누르는 영역만 확대).
5. 탭 48, 2줄 목록 72, 버튼 40으로 높이 고정.
